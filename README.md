# Every Joule KZ — энергия туралы 3D кітап 📖⚡

Мәтін мен жалпақ сызбалардың орнына — қолмен ойнауға болатын тәжірибелер. Қазақ тіліндегі интерактивті 3D физика кітабы: **10 сабақ**, әрқайсысы үш қадамнан тұрады — **болжа**, **тексер**, **дәлелде**.

Techartist-тің [Every Joule](https://iamtechartist.com/every-joule/) кітабынан шабыт алып, қазақ тілінде нөлден жазылды.

## Сабақтар

| № | Тақырып | 3D тәжірибе |
|---|---|---|
| 1 | Энергия қорлары | Заттарды басып, энергияның 6 қорын тап |
| 2 | Кинетикалық және гравитациялық энергия | Доп құлайды: Eп → Eк |
| 3 | Серпімділік энергиясы | Сығылған серіппе блокты итереді |
| 4 | Секірген доп неге тоқтайды | Әр соққыда энергия жылу мен дыбысқа кетеді |
| 5 | Меншікті жылу сыйымдылығы және оқшаулау | Су, май, алюминийді қыздыру |
| 6 | Қуат | 100 Вт пен 400 Вт моторлар жарысы |
| 7 | Пайдалы әсер коэффициенті (ПӘК) | Шам, LED, шәйнек, мотор: пайдалы және шығын ағыны |
| 8 | Электр станциялары және желі | 35–500 кВ: кернеу және сымдағы шығын |
| 9 | Тамақтағы энергия | Алмадағы энергиямен неше қабатқа көтерілеміз |
| 10 | Энергияның сақталу заңы | Маятник: үйкеліспен және үйкеліссіз |

Әр сабақтың соңында оқушы қақпақты ашып, болжамын тексереді және **мөр** алады. Мөрлер браузерде сақталады.

## Іске қосу

Құрастыру қажет емес: таза HTML, CSS және JavaScript (ES modules), Three.js репозиторийдің ішінде.

```bash
git clone https://github.com/<сіздің-логин>/every-joule-kz.git
cd every-joule-kz
python3 -m http.server 8000
# браузерде: http://localhost:8000
```

> Файлды тікелей екі рет басып ашу жұмыс істемейді — ES модульдері үшін жергілікті сервер керек.

## GitHub Pages-те жариялау

1. Репозиторийді GitHub-қа жүктеңіз (`main` тармағы).
2. **Settings → Pages → Source: GitHub Actions** таңдаңыз.
3. `.github/workflows/pages.yml` әр push кезінде сайтты автоматты түрде жариялайды.
4. Мекенжайы: `https://<сіздің-логин>.github.io/every-joule-kz/`

## Құрылым

```
every-joule-kz/
├── index.html            # мұқаба, мазмұны және сабақ беттері
├── teachers.html         # мұғалімге арналған нұсқаулық
├── sources.html          # дереккөздер
├── assets/
│   ├── app.js            # кітап қозғалтқышы: 3D сахна, қадамдар, мөрлер
│   ├── lessons.js        # 10 сабақтың мәтіні мен 3D тәжірибелері
│   ├── book.css          # кітап стилі
│   └── vendor/           # Three.js r169 (MIT)
└── .github/workflows/    # GitHub Pages деплойы
```

## Жаңа сабақ қосу

`assets/lessons.js` файлына жаңа нысан қосыңыз: `title`, `sub`, `intro`, `predict`, `hint`, `setup(ctx)` және `proof`. `setup` ішінде `ink()`, `flow()`, `label()`, `ui.slider()`, `ui.bars()` көмекшілері қолжетімді.
